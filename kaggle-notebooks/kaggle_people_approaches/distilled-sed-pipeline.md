Distilled SED Baseline
Credit and Motivation

This baseline is inspired by work shared by the Kaggle researcher hengck. The implementation adapts his core distillation idea into an existing BirdCLEF-style Sound Event Detection (SED) pipeline.

The main motivation is to transfer the acoustic representation power of the large-scale Perch v2 bird embedding model into a lightweight EfficientNet-based classifier that is practical for competition training and inference.

Core Idea

The system uses representation distillation rather than classic logit distillation.

Instead of copying output probabilities, the model learns to reproduce the internal embeddings generated by the frozen Perch v2 encoder.

The architecture splits training into two independent objectives:

Distillation objective
EfficientNet learns to mimic Perch embeddings using MSE loss.
This transfers rich bioacoustic feature representations learned from 14,795 bird species.
SED classification objective
A separate SED head predicts BirdCLEF labels using detached backbone features.
Gradient flow is intentionally stopped before the SED branch reaches the backbone.

This separation prevents:

representation learning conflicts,
unstable optimization,
catastrophic forgetting of distilled features.

At inference time, the distillation branch is discarded entirely, leaving only the lightweight SED model.

The architecture diagram visualizes a teacher-student distillation pipeline for bird sound event detection.

Left Side — Distillation Learning

The left branch represents:

feature imitation,

Key insight

The EfficientNet backbone is trained to behave like Perch.

The frozen Perch model acts as a teacher encoder.

The student learns semantic acoustic embeddings without needing explicit species probabilities.

This branch controls backbone learning.

Right Side — Detection Learning

The right branch performs:

BirdCLEF classification,
temporal localization,
sound event detection.

The detach() block is the most important component visually.

It indicates:

No classification gradients reach the backbone

This means:

the backbone remains stable,
Perch knowledge is preserved,
SED training cannot distort learned embeddings.
Why This Works Well

This architecture succeeds because:

Perch embeddings already contain rich bird acoustic structure,
EfficientNet becomes a compressed approximation of Perch,
the classifier learns on top of stable high-quality embeddings.

Effectively:

Large foundation model knowledge
            ↓
Compressed into lightweight EfficientNet
            ↓
Fine-tuned for BirdCLEF SED
Architectural Trade-offs
Advantages
Strong Representation Transfer

Perch was trained on massive bird datasets unavailable in BirdCLEF.

Lightweight Inference

Perch is removed after training.

Stable Optimization

Detached gradients avoid destructive multitask interference.

Better Generalization

Distilled embeddings improve robustness on unseen species distributions.

Limitations
Training Cost

Perch inference every batch is extremely expensive.

Memory Usage

Dual-network training increases VRAM demand.

Potential Feature Rigidity

Backbone cannot adapt to downstream classification objectives because of stop-gradient.

Potential Improvements
1. Shared Latent Space

Instead of:

1280 → 1536

Use:

1280 → 512
Perch 1536 → 512

This reduces:

parameter count,
projection mismatch,
memory bandwidth.
2. Larger Backbone

Possible upgrades:

EfficientNet-B2/B3
ConvNeXt
EVA
Audio Spectrogram Transformer (AST)
3. Temporal Modeling

Current architecture is relatively shallow temporally.

Potential additions:

Conformer blocks
GRU/LSTM
Transformer encoders
Temporal convolution networks
4. Offline Perch Embeddings

Precompute teacher embeddings once.

Benefits:

dramatically faster epochs,
lower GPU utilization,
cheaper experimentation.
